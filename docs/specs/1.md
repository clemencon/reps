# Spec: Add a 🍾 to the README

## Objective
Add a single champagne bottle emoji (🍾) at the bottom of `README.md`, as a celebratory touch for readers of the repository. Requested by @clemencon in #1.

## Scope
- In: one 🍾 as static text on the last line of `README.md`.
- Out: any other emoji or smiley, any randomness (script, CI job, hosted image), any change to the rest of the README (mascot GIF, badge, intro, sections).

## Behavior
- `README.md` ends with the existing `## License` section, then a blank line, then a line containing only `🍾`, then a single trailing newline.
- "Random" reduces to one fixed choice: the set is only 🍾.

## Acceptance criteria
1. The last non-empty line of `README.md` is exactly `🍾`.
2. `README.md` contains `🍾` exactly once.
3. The file ends with exactly one trailing newline.
4. The diff touches only the end of `README.md` (plus this spec); all earlier lines are unchanged.
5. Existing checks (`pnpm test`, lint) still pass.

## Assumptions
- The emoji goes on its own line after a blank line, below the License section, not inside it.
- No automated test is added; the criteria can be checked with a shell command such as `tail -n 1 README.md`.
- Plain-text viewers that lack the glyph may show a fallback; this is accepted.
